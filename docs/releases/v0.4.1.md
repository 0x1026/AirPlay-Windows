# AirPlay Windows v0.4.1 — GPU decoding and connection recovery fixes

## Fixes

- Mirroring now attaches the renderer before initializing the decoder, so
  enabled GPU acceleration can use the renderer's D3D11 device. Previously,
  H.264 and HEVC mirroring silently used software decoding despite the GPU
  being ready. Explicit CPU mode remains available.
- Diagnostics use multiple columns and rows according to window width. The
  navigation and settings panels reserve space for the diagnostics area,
  preventing overlap and truncation of the previous single-line layout.
- Control connections use TCP keepalive probes to detect unreachable senders.
  When a connection ends without TEARDOWN, media transports are stopped and
  the matching active session is cleared instead of leaving a frozen image.
  Cleanup from an older connection does not clear a newer active session.
- Runtime frame dumps and ImGui state are excluded from Git.

## Validation

- All five CTest regression suites and all 26 pair-verify protocol checks pass.
- Socket tests cover keepalive settings, a reachable idle connection,
  abrupt reset cleanup and reconnection. A new integration test covers
  reset/EOF without TEARDOWN and protection of a newer active session.
- D3D11 hardware tests passed on an NVIDIA GeForce RTX 3080 Laptop GPU.
- Live iPhone 16 testing confirmed H.264 and HEVC decoding in both GPU and
  CPU modes. Rotation, manual reconnection, diagnostics, pause/resume,
  seeking, lock/unlock and MP4 playback were also checked. Audio/video
  synchronization was assessed by listening and viewing, not measured.
- A real Wi-Fi interruption was detected in approximately ten seconds,
  returning the receiver to idle; manual AirPlay reconnection succeeded
  without restarting the application.
- Mirroring over the iPhone's Wi-Fi Personal Hotspot was reported working.

## Limits

Automatic sender reconnection after network loss is not guaranteed. Keepalive
detection time depends on network conditions. These checks do not constitute
exhaustive testing across devices, drivers or long-running sessions.
This release does not add AirPlay discovery over VPN or Apple's peer-to-peer
radio discovery mode.
